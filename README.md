### Step 2: Make Changes
**Via GitHub Web UI:**
1. Go to https://github.com/tmoneysurvey/galacticos-website
2. Click `index.html`
3. Click ✏️ (edit button)
4. Find and edit text
5. Scroll down → "Commit changes"
6. Add message (e.g., "Update fall season news")
7. Click "Commit to main"
8. **Done!** Site updates in ~30 seconds
